# 轮末全量恢复 + 跨会话自愈是已定义行为

轮次结束的恢复不按会话过滤、恢复账本全集：单 host 进程内账本即全集，另一会话再触达同文件会重新转换并自愈。并发场景（后台 subagent、任务看板 cron 与主会话轮末恢复竞争）下，可能出现的过期编辑通过版本过期报错触发重新读取回到一致。强串行方案（探测活跃会话、跳过其触达的文件）被拒绝：复杂度高、引入死锁面，且自愈路径已实测可靠。

## Consequences

- 模型收到版本过期类报错时 re-read 即可，属正常流程而非故障。
- 跨轮次文件在原编码与 UTF-8 间交替是预期的磁盘状态，不视为抖动缺陷。
